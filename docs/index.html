API Reference

🗺️ Identity Map

Two-level observable cache ensures every reference to the same record points to a single instance. No stale data, no duplicates.

🔌 Pluggable Adapters

REST, JSON:API, OData — or write your own. Adapters abstract away protocol differences so your models stay clean.

🔄 Serializers

Transform API payloads into normalized records and back. Supports embedded records, custom key mappings, and more.

🤖 State Machines

Every record tracks its lifecycle — loading, saving, dirty, invalid — as observable state your UI can react to.

🏗️ Framework Agnostic

Works with React, Vue, Solid, Svelte, or plain JavaScript. Anywhere MobX runs, mobx-data runs.

📐 TypeScript First

Full generic types, decorator metadata, and strict mode support out of the box.
