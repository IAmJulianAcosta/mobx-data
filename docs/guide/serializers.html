Serializers ​

Serializers transform raw API payloads into normalized records (deserialization) and convert records back into the format the API expects (serialization). They handle key mapping, embedded records, and type coercion.

Built-in Serializers ​

SerializerFormatUse case
JsonSerializerPlain JSONStandard REST APIs with flat JSON
RestSerializerREST conventionsAPIs that wrap resources in a root key
JsonApiSerializerJSON:APIJSON:API spec-compliant backends

JsonSerializer ​

For APIs that return flat JSON objects:

ts
import { JsonSerializer } from 'mobx-data';

store.registerSerializer('application', new JsonSerializer());

Expected API format:

json
// GET /users/1
{
  "id": "1",
  "name": "Alice",
  "email_address": "alice@example.com",
  "created_at": "2024-01-15T10:30:00Z"
}

// GET /users
[
  { "id": "1", "name": "Alice" },
  { "id": "2", "name": "Bob" }
]

RestSerializer ​

For APIs that nest resources under a root key:

ts
import { RestSerializer } from 'mobx-data';

store.registerSerializer('application', new RestSerializer());

Expected format:

json
// GET /users/1
{
  "user": {
    "id": "1",
    "name": "Alice",
    "posts": ["10", "11"]
  }
}

// GET /users
{
  "users": [
    { "id": "1", "name": "Alice" },
    { "id": "2", "name": "Bob" }
  ]
}

Sideloaded Records ​

The RestSerializer automatically pushes sideloaded records into the store:

json
{
  "user": { "id": "1", "name": "Alice", "posts": ["10"] },
  "posts": [{ "id": "10", "title": "Hello World", "author": "1" }]
}

JsonApiSerializer ​

For JSON:API compliant backends:

ts
import { JsonApiSerializer } from 'mobx-data/json-api';

store.registerSerializer('application', new JsonApiSerializer());

Handles the full JSON:API document structure:

json
{
  "data": {
    "type": "users",
    "id": "1",
    "attributes": { "name": "Alice" },
    "relationships": {
      "posts": { "data": [{ "type": "posts", "id": "10" }] }
    }
  },
  "included": [
    { "type": "posts", "id": "10", "attributes": { "title": "Hello" } }
  ]
}

Key Mapping ​

By default, serializers handle case conversion between your models and the API:

Model (camelCase)API (depends on serializer)
firstNamefirst_name (snake_case for REST)
firstNamefirst-name (kebab-case for JSON:API)

Custom Key Mapping ​

Override keyForAttribute or keyForRelationship:

ts
class MySerializer extends JsonSerializer {
  keyForAttribute(key: string): string {
    return snakeCase(key); // camelCase → snake_case
  }

  keyForRelationship(key: string): string {
    return `${snakeCase(key)}_id`; // author → author_id
  }
}

Attribute Serialization ​

serialize(record, options?) ​

Converts a record into the API payload format:

ts
// For a POST request, the serializer produces:
{
  "title": "New Post",
  "body": "Content",
  "author_id": "1"
}

normalize(modelName, payload) ​

Converts an API response into the internal format:

ts
// Input (from API):
{ "user_name": "alice", "email_address": "alice@ex.com" }

// Output (normalized):
{ id: "1", type: "user", attributes: { userName: "alice", emailAddress: "alice@ex.com" } }

Embedded Records ​

Use the EmbeddedRecordsMixin for APIs that nest full related records:

ts
import { RestSerializer, EmbeddedRecordsMixin } from 'mobx-data/serializer';

class PostSerializer extends EmbeddedRecordsMixin(RestSerializer) {
  attributes = {
    author: { embedded: 'always' },
    comments: { embedded: 'always' },
  };
}

store.registerSerializer('post', new PostSerializer());

Handles payloads like:

json
{
  "post": {
    "id": "1",
    "title": "Hello",
    "author": { "id": "5", "name": "Alice" },
    "comments": [
      { "id": "100", "body": "Great post!" }
    ]
  }
}

Custom Serializers ​

Implement the Serializer interface:

ts
import { Serializer } from 'mobx-data/serializer';

class CsvSerializer extends Serializer {
  // `modelClass` is a ModelClassMeta view — { modelName, attributes, relationships } —
  // not the model constructor. Iterate `modelClass.attributes` to walk the schema.
  normalizeResponse(store, modelClass, payload, id, requestType) {
    // Parse CSV → normalized records
  }

  serialize(snapshot, options) {
    // Record → CSV row
  }
}

Per-Model Serializers ​

ts
store.registerSerializer('application', new JsonSerializer());
store.registerSerializer('legacy-report', new CsvSerializer());
