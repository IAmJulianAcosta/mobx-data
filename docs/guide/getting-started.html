Getting Started ​

Installation ​

sh
pnpm add mobx-data mobx reflect-metadata
sh
npm install mobx-data mobx reflect-metadata
sh
yarn add mobx-data mobx reflect-metadata

Prerequisites ​

  • Node.js 18+
  • TypeScript 5.5+ (recommended)
  • MobX 6+

Your tsconfig.json needs decorators enabled:

json
{
  "compilerOptions": {
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true,
    "useDefineForClassFields": false
  }
}

Quick Start ​

1. Import reflect-metadata ​

At the top of your application entry point:

ts
import 'reflect-metadata';

2. Define a Model ​

ts
import { Model, attr, belongsTo, hasMany } from 'mobx-data';

class User extends Model {
  static modelName = 'user';

  @attr('string') declare name: string;
  @attr('number') declare age: number;
  @attr('boolean') declare isAdmin: boolean;

  @hasMany('post') declare posts: Post[];
}

class Post extends Model {
  static modelName = 'post';

  @attr('string') declare title: string;
  @attr('string') declare body: string;
  @attr('date') declare publishedAt: Date;

  @belongsTo('user') declare author: User;
}

3. Set Up the Store ​

ts
import { Store, RestAdapter, JsonSerializer } from 'mobx-data';

const store = new Store();

// Register adapter and serializer
store.registerAdapter('application', new RestAdapter({
  host: 'https://api.example.com',
  namespace: 'v1',
}));

store.registerSerializer('application', new JsonSerializer());

// Register models
store.registerModel(User);
store.registerModel(Post);

4. Fetch and Use Data ​

ts
// Find a single record
const user = await store.findRecord('user', '1');
console.log(user.name); // "Alice"

// Find all records
const posts = await store.findAll('post');
posts.forEach(post => console.log(post.title));

// Create a new record
const newPost = store.createRecord('post', {
  title: 'Hello World',
  body: 'My first post!',
  author: user,
});

// Save to server
await newPost.save();

5. React to Changes ​

Because everything is MobX observable, your UI updates automatically:

tsx
// React example
import { observer } from 'mobx-react-lite';

const UserProfile = observer(({ userId }) => {
  const user = store.peekRecord('user', userId);

  if (!user) return <div>Loading...</div>;

  return (
    <div>
      <h1>{user.name}</h1>
      <p>Posts: {user.posts.length}</p>
      {user.isSaving && <span>Saving...</span>}
    </div>
  );
});
