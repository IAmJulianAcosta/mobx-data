Request Manager ​

The RequestManager implements a middleware pipeline for HTTP requests. It sits between the adapter and the actual network call, allowing you to add caching, authentication, retry logic, and instrumentation as composable handlers.

Architecture ​

Adapter → RequestManager → Handler₁ → Handler₂ → ... → FetchHandler → Network
                                                              ↓
         Response ← CacheHandler ← Handler₂ ← Handler₁ ← Response

Each handler in the chain can:

  • Modify the request before passing it forward
  • Short-circuit and return a cached response
  • Modify the response on the way back
  • Perform side effects (logging, metrics)

Setup ​

ts
import { RequestManager, FetchHandler, CacheHandler } from 'mobx-data/request';

const requestManager = new RequestManager();

// Handlers execute in order — last handler should perform the actual fetch
requestManager.use([
  new CacheHandler(),      // Check cache first
  new AuthHandler(),       // Add auth headers
  new RetryHandler(),      // Retry on failure
  new FetchHandler(),      // Perform HTTP request
]);

FetchHandler ​

The terminal handler that performs the actual HTTP request using the Fetch API:

ts
import { FetchHandler } from 'mobx-data/request';

// Basic usage
new FetchHandler();

// With custom fetch options
new FetchHandler({
  credentials: 'include',
  mode: 'cors',
});

CacheHandler ​

Caches responses based on configurable strategies:

ts
import { CacheHandler } from 'mobx-data/request';

new CacheHandler({
  // Cache GET requests for 5 minutes
  lifetime: 5 * 60 * 1000,

  // Only cache findRecord and findAll
  types: ['findRecord', 'findAll'],
});

Cache Invalidation ​

The cache is invalidated automatically when:

  • A record is created, updated, or deleted
  • store.unloadAll(modelName) is called
  • The cache lifetime expires

Manual invalidation:

ts
requestManager.cache.clear();
requestManager.cache.invalidate('user'); // Clear all user caches

Writing Custom Handlers ​

A handler is an object with a request method:

ts
import type { RequestContext, NextFn, RequestHandler } from 'mobx-data/request';

class LoggingHandler implements RequestHandler {
  async request(context: RequestContext, next: NextFn) {
    const start = performance.now();
    console.log(`→ ${context.request.method} ${context.request.url}`);

    const response = await next(context);

    const duration = performance.now() - start;
    console.log(`← ${response.status} (${duration.toFixed(0)}ms)`);

    return response;
  }
}

Request Context ​

ts
interface RequestContext {
  request: {
    url: string;
    method: string;
    headers: Record<string, string>;
    body?: unknown;
  };
  op: string;           // 'findRecord', 'query', 'createRecord', etc.
  modelName: string;
  id?: string;
}

Common Handler Patterns ​

Authentication ​

ts
class AuthHandler implements RequestHandler {
  constructor(private tokenStore: { token: string }) {}

  async request(context: RequestContext, next: NextFn) {
    context.request.headers['Authorization'] = `Bearer ${this.tokenStore.token}`;
    return next(context);
  }
}

Retry with Backoff ​

ts
class RetryHandler implements RequestHandler {
  constructor(private maxRetries = 3) {}

  async request(context: RequestContext, next: NextFn) {
    let lastError: Error | undefined;

    for (let attempt = 0; attempt <= this.maxRetries; attempt++) {
      try {
        return await next(context);
      } catch (error) {
        lastError = error as Error;
        if (attempt < this.maxRetries) {
          await new Promise(resolve =>
            setTimeout(resolve, Math.pow(2, attempt) * 1000)
          );
        }
      }
    }

    throw lastError;
  }
}

Request Deduplication ​

ts
class DedupeHandler implements RequestHandler {
  private inflight = new Map<string, Promise<unknown>>();

  async request(context: RequestContext, next: NextFn) {
    if (context.request.method !== 'GET') {
      return next(context);
    }

    const key = context.request.url;
    const existing = this.inflight.get(key);
    if (existing) return existing;

    const promise = next(context).finally(() => this.inflight.delete(key));
    this.inflight.set(key, promise);
    return promise;
  }
}

Integration with Store ​

The RequestManager integrates transparently — adapters use it internally:

ts
const adapter = new RestAdapter({
  host: 'https://api.example.com',
  requestManager: new RequestManager().use([
    new CacheHandler({ lifetime: 60_000 }),
    new AuthHandler(authStore),
    new FetchHandler(),
  ]),
});
