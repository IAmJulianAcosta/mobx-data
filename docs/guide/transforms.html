Transforms ​

Transforms convert attribute values between their JavaScript representation (used in your app) and their serialized representation (sent over the wire). They're applied automatically during serialization and deserialization.

Built-in Transforms ​

NameJS TypeWire TypeDescription
'string'stringstringPass-through, coerces null to ''
'number'numbernumberParses strings, coerces null to 0
'boolean'booleanbooleanCoerces truthy/falsy values
'date'DatestringISO 8601 serialization

Usage ​

ts
import { Model, attr } from 'mobx-data';

class Event extends Model {
  static modelName = 'event';

  @attr('string') declare name: string;
  @attr('number') declare capacity: number;
  @attr('boolean') declare isPublic: boolean;
  @attr('date') declare startsAt: Date;
}

How Transforms Work ​

When the serializer processes a record:

  1. Deserialize (API → App): transform.deserialize(rawValue) is called on each attribute
  2. Serialize (App → API): transform.serialize(appValue) is called before sending
ts
// Date transform example:
// API returns: "2024-03-15T10:30:00Z"
// App sees:    new Date("2024-03-15T10:30:00Z")

// App sets:    new Date(2024, 2, 16)
// API receives: "2024-03-16T00:00:00.000Z"

Custom Transforms ​

Create a transform by implementing the Transform interface:

ts
import { Transform } from 'mobx-data/transforms';

interface Money {
  amount: number;
  currency: string;
}

const moneyTransform: Transform<Money, { amount: number; currency: string }> = {
  serialize(value: Money) {
    return { amount: Math.round(value.amount * 100), currency: value.currency };
  },

  deserialize(raw: { amount: number; currency: string }): Money {
    return { amount: raw.amount / 100, currency: raw.currency };
  },
};

Registering Custom Transforms ​

ts
store.registerTransform('money', moneyTransform);

Using Custom Transforms ​

ts
class Product extends Model {
  static modelName = 'product';

  @attr('string') declare name: string;
  @attr('money') declare price: Money;
}

Common Custom Transform Examples ​

JSON String ​

Store a JSON object but serialize it as a string:

ts
const jsonTransform: Transform<object, string> = {
  serialize(value: object): string {
    return JSON.stringify(value);
  },
  deserialize(raw: string): object {
    return typeof raw === 'string' ? JSON.parse(raw) : raw;
  },
};

Enum ​

Map between string enums and numeric codes:

ts
enum Status { Active = 'active', Inactive = 'inactive', Pending = 'pending' }

const statusCodes = { active: 1, inactive: 2, pending: 3 };
const codeToStatus = Object.fromEntries(
  Object.entries(statusCodes).map(([k, v]) => [v, k])
);

const statusTransform: Transform<Status, number> = {
  serialize(value: Status): number {
    return statusCodes[value];
  },
  deserialize(raw: number): Status {
    return codeToStatus[raw] as Status;
  },
};

Array of Primitives ​

ts
const stringArrayTransform: Transform<string[], string> = {
  serialize(value: string[]): string {
    return value.join(',');
  },
  deserialize(raw: string): string[] {
    return raw ? raw.split(',') : [];
  },
};

Null Handling ​

Built-in transforms handle null and undefined gracefully:

  • 'string': null → ''
  • 'number': null → 0
  • 'boolean': null → false
  • 'date': null → null (dates are nullable by default)

For custom transforms, you should handle null explicitly:

ts
const moneyTransform: Transform<Money | null, unknown> = {
  serialize(value: Money | null) {
    if (!value) return null;
    return { amount: value.amount * 100, currency: value.currency };
  },
  deserialize(raw: unknown): Money | null {
    if (!raw) return null;
    const data = raw as { amount: number; currency: string };
    return { amount: data.amount / 100, currency: data.currency };
  },
};
