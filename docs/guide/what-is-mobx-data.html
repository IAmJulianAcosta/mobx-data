What is mobx-data? ​

mobx-data is a feature-complete port of Ember Data to MobX. It provides the same battle-tested data-layer patterns — Identity Map, pluggable adapters and serializers, record state machines, and async relationships — but powered by MobX observables instead of Ember's computed property system.

Why? ​

Ember Data solved the hardest problems of client-side data management years ago:

  • Identity — one record, one object. No stale copies floating around.
  • Protocol abstraction — swap REST for JSON:API without touching your components.
  • Lifecycle management — know exactly whether a record is loading, dirty, saving, or errored.
  • Relationship resolution — traverse a record graph without manually wiring up fetches.

But Ember Data is locked to the Ember framework. mobx-data brings these patterns to any app that uses MobX.

Design Principles ​

PrincipleWhat it means
Framework-agnosticReact, Vue, Solid, Svelte, plain JS — if MobX runs there, mobx-data does too
Observable all the way downEvery piece of state is a MobX observable — no glue code needed
TypeScript-firstFull generic types, decorator metadata, strict mode
ModularImport only the pieces you need: mobx-data/store, mobx-data/json-api, etc.
FamiliarIf you've used Ember Data, you already know the API

When to Use mobx-data ​

mobx-data is a great fit when:

  • Your app talks to a REST or JSON:API backend and you want structured data management
  • You already use MobX and want a data layer that integrates seamlessly
  • You need dirty tracking, rollback, and lifecycle hooks
  • You're migrating from Ember and want to keep the familiar data patterns
  • You want a single source of truth (Identity Map) across your entire app
