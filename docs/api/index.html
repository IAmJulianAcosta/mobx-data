API Reference ​

This section documents the public API of mobx-data. Each module is available as a separate import path for tree-shaking:

ts
import { Store } from 'mobx-data/store';
import { Model, attr, belongsTo, hasMany } from 'mobx-data/model';
import { RestAdapter } from 'mobx-data/adapter';
import { JsonSerializer } from 'mobx-data/serializer';
import { RequestManager } from 'mobx-data/request';
import { JsonApiAdapter, JsonApiSerializer } from 'mobx-data/json-api';
import { ODataAdapter } from 'mobx-data/odata';

Or import everything from the root:

ts
import { Store, Model, attr, RestAdapter, JsonSerializer } from 'mobx-data';

Type Exports ​

All public interfaces and types are exported from their respective modules and are available for TypeScript consumers via mobx-data/<module>.
