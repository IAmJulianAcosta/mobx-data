Store ​

ts
import { Store } from 'mobx-data/store';

Class: Store ​

Central store — the top-level coordinator for the mobx-data runtime. Orchestrates the identity map, adapters, serializers, and record lifecycle.

Properties ​

PropertyTypeDescription
schemaSchemaServiceSchema registry for model classes and metadata
identityMapIdentityMapTwo-level cache: modelName → id → record

Registration Methods ​

registerAdapter(modelName, adapter) ​

ts
registerAdapter(modelName: string, adapter: AdapterLike): void

Registers an adapter for a model name. Use 'application' as the fallback adapter.

registerSerializer(modelName, serializer) ​

ts
registerSerializer(modelName: string, serializer: SerializerLike): void

Registers a serializer for a model name. Use 'application' as the fallback serializer.

registerModel(modelClass) ​

ts
registerModel(modelClass: typeof Model): void

Registers a model class with the schema service.

Finding Records ​

findRecord(modelName, id, options?) ​

ts
findRecord(modelName: string, id: string, options?: FindOptions): Promise<Model>

Fetches a single record by ID. Delegates to the adapter and normalizes the response through the serializer.

Options:

OptionTypeDefaultDescription
reloadbooleantrueBypass cache and hit the network
backgroundReloadboolean-Return cached value, refetch in background
includestring-Relationship paths to sideload
adapterOptionsobject-Forwarded to the adapter

findAll(modelName, options?) ​

ts
findAll(modelName: string, options?: FindOptions): Promise<RecordArray>

Fetches all records of a type.

query(modelName, params) ​

ts
query(modelName: string, params: Record<string, unknown>): Promise<AdapterPopulatedRecordArray>

Sends a query to the adapter with arbitrary parameters.

queryRecord(modelName, params) ​

ts
queryRecord(modelName: string, params: Record<string, unknown>): Promise<Model>

Like query, but expects a single record in the response.

Peeking (Synchronous) ​

peekRecord(modelName, id) ​

ts
peekRecord(modelName: string, id: string): Model | null

Returns the record from the identity map, or null. No network request.

peekAll(modelName) ​

ts
peekAll(modelName: string): RecordArray

Returns a live RecordArray of all loaded records of the type.

Creating Records ​

createRecord(modelName, attributes?) ​

ts
createRecord(modelName: string, attributes?: Record<string, unknown>): Model

Creates a new record locally (not persisted). The record starts in loaded.created.uncommitted state.

Saving ​

saveRecord(record, options?) ​

ts
saveRecord(record: Model, options?: SaveOptions): Promise<Model>

Persists a record. Calls adapter.createRecord or adapter.updateRecord depending on record.isNew.

Pushing Data ​

push(document) ​

ts
push(document: NormalizedDocument): Model | Model[] | null

Pushes a pre-normalized document into the identity map. Existing records are merged in place.

Unloading ​

unloadRecord(record) ​

ts
unloadRecord(record: Model): void

Removes a record from the identity map.

unloadAll(modelName?) ​

ts
unloadAll(modelName?: string): void

Removes all records of a type (or all records) from the identity map.

Interface: AdapterLike ​

Minimal adapter interface the Store depends on:

ts
interface AdapterLike {
  findRecord(store, modelName, id, snapshot): Promise<unknown>;
  findAll(store, modelName, sinceToken, snapshotArray): Promise<unknown>;
  findMany?(store, modelName, ids, snapshots): Promise<unknown>;
  query(store, modelName, query, recordArray): Promise<unknown>;
  queryRecord(store, modelName, query): Promise<unknown>;
  createRecord(store, modelName, snapshot): Promise<unknown>;
  updateRecord(store, modelName, snapshot): Promise<unknown>;
  patchRecord?(store, modelName, snapshot): Promise<unknown>;
  deleteRecord(store, modelName, snapshot): Promise<unknown>;
  coalesceFindRequests?: boolean;
}
