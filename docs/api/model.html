Class: Model (abstract) ​

Base class for all mobx-data model records. Manages the complete lifecycle of a server-side resource with MobX observables.

Relationship Proxies ​

ManyArray ​

Observable array-like for sync hasMany relationships. Extends Array with:

  • pushObject(record) — add and track inverse
  • removeObject(record) — remove and untrack inverse

AsyncBelongsTo<T> ​

Promise-like proxy for async belongsTo. Resolves to the related record.

AsyncHasMany<T> ​

Promise-like proxy for async hasMany. Resolves to an array of related records.
