Class: MdqlValidator ​

Static methods for validating MdqlQueryObject against a SchemaService.

validate(query, schema) ​

ts
static validate(query: MdqlQueryObject, schema: SchemaService): void

Throws MdqlValidationException on the first error found.

validateQuiet(query, schema) ​

ts
static validateQuiet(query: MdqlQueryObject, schema: SchemaService): MdqlValidationError[]

Returns an array of all validation errors without throwing.

Validation Rules ​

  • Model name must exist in the schema.
  • Filter fields must be registered attributes (dot-paths for nested attributes are supported).
  • Operators must be valid for the field's attribute type.
  • between requires a [min, max] array value.
  • in/notIn require array values.
  • orderBy fields must be registered attributes.
  • includes must be registered relationships.
  • limit must be a positive integer or null.
  • offset must be a non-negative integer or null.

Class: MdqlMemoryExecutor ​

Static methods for executing queries against in-memory record arrays.

executeMany(items, query, schema) ​

ts
static executeMany<T>(items: T[], query: MdqlQueryObject, schema: SchemaService): T[]

Applies the full pipeline: filter, sort, paginate. Returns matching records.

executeOne(items, query, schema) ​

ts
static executeOne<T>(items: T[], query: MdqlQueryObject, schema: SchemaService): T | null

Returns the first matching record or null.

count(items, query, schema) ​

ts
static count<T>(items: T[], query: MdqlQueryObject, schema: SchemaService): number

Returns the count of matching records.

exists(items, query, schema) ​

ts
static exists<T>(items: T[], query: MdqlQueryObject, schema: SchemaService): boolean

Returns whether any records match.

compilePredicate(query, schema) ​

ts
static compilePredicate<T>(query: MdqlQueryObject, schema: SchemaService): (record: T) => boolean

Returns a standalone predicate function for use with toLiveArray() and reactive MobX computations.

type MdqlOperator =

  | 'greaterThan' | 'greaterThanOrEquals' | 'lessThan' | 'lessThanOrEquals'
  | 'between';
