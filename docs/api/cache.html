Cache Utility Functions ​

parseCacheTTLFromHeaders(headers) ​

ts
parseCacheTTLFromHeaders(headers: Record<string, string>): number | null

Parses HTTP cache headers into a TTL in milliseconds.

  • Cache-Control: no-store or no-cache returns 0 (do not cache).
  • Cache-Control: s-maxage=N returns N * 1000 (takes priority over max-age).
  • Cache-Control: max-age=N returns N * 1000.
  • Expires: <date> returns time until that date.
  • No recognized headers returns null.
