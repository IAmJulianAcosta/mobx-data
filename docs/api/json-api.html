JSON:API ​

ts
import { JsonApiAdapter, JsonApiSerializer } from 'mobx-data/json-api';

Class: JsonApiAdapter extends RestAdapter ​

Adapter for JSON:API spec-compliant backends.

Differences from RestAdapter ​

  • Sets Content-Type: application/vnd.api+json and Accept: application/vnd.api+json
  • Supports include parameter for compound documents
  • Handles JSON:API error objects
  • Uses dasherized, pluralized paths by default
  • Supports sparse fieldsets via fields param

Constructor ​

ts
new JsonApiAdapter({
  host?: string;
  namespace?: string;
  headers?: Record<string, string>;
  coalesceFindRequests?: boolean;
})

Query Parameters ​

Translates query objects into JSON:API query format:

ts
store.query('article', {
  filter: { author: '5' },
  include: 'comments,author',
  fields: { article: 'title,body', person: 'name' },
  sort: '-publishedAt',
  page: { number: 1, size: 25 },
});

Generates:

GET /articles?filter[author]=5&include=comments,author&fields[article]=title,body&fields[person]=name&sort=-publishedAt&page[number]=1&page[size]=25

Class: JsonApiSerializer extends Serializer ​

Handles the full JSON:API document structure.

Normalization ​

Converts JSON:API documents into NormalizedDocument:

json
{
  "data": { "type": "articles", "id": "1", "attributes": {...} },
  "included": [...]
}
  • data → primary resource(s)
  • included → sideloaded resources pushed into the store
  • relationships.*.data → relationship references
  • errors → field-level validation errors

Serialization ​

Converts record snapshots into JSON:API format:

json
{
  "data": {
    "type": "articles",
    "id": "1",
    "attributes": { "title": "Hello" },
    "relationships": {
      "author": { "data": { "type": "people", "id": "5" } }
    }
  }
}

Error Extraction ​

Parses JSON:API error objects:

json
{
  "errors": [{
    "status": "422",
    "source": { "pointer": "/data/attributes/title" },
    "detail": "is required"
  }]
}

Maps source.pointer to attribute names for the Errors collection.
