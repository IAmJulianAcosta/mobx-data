Schema & Decorators ​

ts
import { attr, belongsTo, hasMany, SchemaService } from 'mobx-data/schema';

Decorators ​

@attr(type?, options?) ​

Marks a class property as a serializable attribute.

ts
// Signatures:
function attr(type?: string | null, options?: AttributeOptions): PropertyDecorator;
function attr(options: AttributeOptions): PropertyDecorator;

Parameters:

ParameterTypeDescription
typestring | nullTransform name ('string', 'number', 'boolean', 'date', or custom)
optionsAttributeOptionsAdditional options

Examples:

ts
@attr('string') declare name: string;
@attr('number', { defaultValue: 0 }) declare age: number;
@attr({ defaultValue: () => [] }) declare tags: string[];
@attr() declare metadata: unknown; // no transform (pass-through)

@belongsTo(type, options?) ​

Declares a many-to-one association.

ts
function belongsTo(type: string, options?: RelationshipOptions): PropertyDecorator;

Parameters:

ParameterTypeDescription
typestringmodelName of the related model
optionsRelationshipOptionsRelationship configuration

Examples:

ts
@belongsTo('user') declare author: User;
@belongsTo('team', { async: true }) declare team: Team;
@belongsTo('category', { inverse: null }) declare category: Category;
@belongsTo('commentable', { polymorphic: true }) declare parent: Model;

@hasMany(type, options?) ​

Declares a one-to-many association.

ts
function hasMany(type: string, options?: RelationshipOptions): PropertyDecorator;

Parameters:

ParameterTypeDescription
typestringmodelName of the related model
optionsRelationshipOptionsRelationship configuration

Examples:

ts
@hasMany('post', { inverse: 'author' }) declare posts: Post[];
@hasMany('tag', { async: true }) declare tags: Tag[];
@hasMany('comment') declare comments: Comment[];

Interfaces ​

AttributeDef ​

Shape of a single @attr decoration.

ts
interface AttributeDef {
  name: string;           // Property name on the model
  type: string | null;    // Transform type or null for pass-through
  options: AttributeOptions;
  isAttribute: true;      // Discriminant for narrowing
}

AttributeOptions ​

ts
interface AttributeOptions {
  defaultValue?: unknown | (() => unknown);
  [key: string]: unknown;   // Custom options forwarded to transforms
}

RelationshipDef ​

Shape of a single @belongsTo / @hasMany decoration.

ts
interface RelationshipDef {
  name: string;                    // Property name
  kind: 'belongsTo' | 'hasMany';  // Direction
  type: string;                    // Related model's modelName
  options: RelationshipOptions;
  isRelationship: true;            // Discriminant
}

RelationshipOptions ​

ts
interface RelationshipOptions {
  async?: boolean;           // Default: false
  inverse?: string | null;   // Default: auto-detected
  polymorphic?: boolean;     // Default: false
  [key: string]: unknown;
}

Class: SchemaService ​

Central registry for model classes and their metadata. Decorators write metadata via reflect-metadata; SchemaService reads it by walking the prototype chain.

Methods ​

registerModel(modelClass) ​

ts
registerModel(modelClass: typeof Model): void

Registers a model class and indexes its attribute and relationship metadata.

modelFor(modelName) ​

ts
modelFor(modelName: string): typeof Model

Returns the registered model class for a model name.

attributesFor(modelName) ​

ts
attributesFor(modelName: string): Map<string, AttributeDef>

Returns all attribute definitions (including inherited) for a model.

relationshipsFor(modelName) ​

ts
relationshipsFor(modelName: string): Map<string, RelationshipDef>

Returns all relationship definitions (including inherited) for a model.
