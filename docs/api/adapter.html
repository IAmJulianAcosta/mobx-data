Class: Adapter (abstract) ​

Abstract base class for all adapters. Translates store operations into network requests.

Properties ​

PropertyTypeDefaultDescription
hoststring''Base URL prefix (e.g. https://api.example.com)
namespacestring''Path segment after host (e.g. v2)
headersRecord<string, string>{}Default request headers
coalesceFindRequestsbooleanfalseBatch findRecord calls into findMany

URL Building Methods ​

buildURL(modelName, id, snapshot, requestType, query?) ​

Dispatches to the appropriate urlFor* method based on the request type.

pathForType(modelName) ​

ts
pathForType(modelName: string): string

Returns the URL path segment. Default: dasherized, pluralized.
Example: 'userPost' → 'user-posts'

Caching Strategy Methods ​

shouldReloadRecord(store, snapshot) ​

Returns true when the store should bypass cache. Default: false.

shouldBackgroundReloadRecord(store, snapshot) ​

Returns true to schedule a background reload. Default: true.

shouldReloadAll(store, snapshotRecordArray) ​

Returns true to force reload on findAll. Default: false.

shouldBackgroundReloadAll(store, snapshotRecordArray) ​

Returns true to background-reload collections. Default: true.

Utility Methods ​

groupRecordsForFindMany(store, snapshots) ​

ts
groupRecordsForFindMany(store, snapshots: AdapterSnapshot[]): AdapterSnapshot[][]

Groups snapshots into batches for findMany. Default: single batch.

patchRecord(store, modelName, snapshot) ​

Persists only changed attributes (PATCH). Default: delegates to updateRecord.

Class: RestAdapter extends Adapter ​

Concrete adapter for standard REST APIs. Performs HTTP requests using the Fetch API.

Interface: AdapterSnapshot ​

A frozen view of a record passed to adapter methods.

ts
interface AdapterSnapshot {
  id: string | null;
  modelName: string;
  attr(key: string): unknown;
  belongsTo(key: string, options?: { id: boolean }): unknown;
  hasMany(key: string, options?: { ids: boolean }): unknown;
  changedAttributes(): Record<string, [unknown, unknown]>;
  record: unknown;
}
