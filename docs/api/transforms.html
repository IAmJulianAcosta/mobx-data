Transforms ​

ts
import { Transform } from 'mobx-data/transforms';

Interface: Transform<T, S> ​

Converts attribute values between their JavaScript type (T) and serialized wire type (S).

ts
interface Transform<T, S> {
  serialize(value: T): S;
  deserialize(raw: S): T;
}

Type Parameters ​

ParameterDescription
TJavaScript type used in the app (e.g., Date)
SSerialized type sent over the wire (e.g., string)

Built-in Transforms ​

string ​

ts
Transform<string, string>
  • deserialize: coerces null/undefined to ''
  • serialize: returns the string as-is

number ​

ts
Transform<number, number>
  • deserialize: parses strings via Number(), coerces null to 0
  • serialize: returns the number as-is

boolean ​

ts
Transform<boolean, boolean>
  • deserialize: coerces truthy/falsy values
  • serialize: returns true or false

date ​

ts
Transform<Date, string>
  • deserialize: parses ISO 8601 string into Date object
  • serialize: calls toISOString() on the Date

Registering Custom Transforms ​

ts
store.registerTransform('currency', {
  serialize(value: number): number {
    return Math.round(value * 100); // dollars → cents
  },
  deserialize(raw: number): number {
    return raw / 100; // cents → dollars
  },
});

Then use in a model:

ts
@attr('currency') declare price: number;

Transform Lookup ​

Transforms are resolved by name at serialization/deserialization time:

  1. Check the store's transform registry for an exact name match
  2. If not found, treat the attribute as pass-through (no transformation)

A null type in @attr() means no transform is applied — the raw value is used as-is.
